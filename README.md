# Igor Bogdanov Portfolio

## 🚀 Как запустить сайт за 2 минуты (Самый простой способ)

1. **GitHub**: Создайте новый репозиторий на GitHub.
2. **Загрузка**: Нажмите "uploading an existing file" и просто перетащите сюда все файлы из этой папки. Нажмите "Commit".
3. **Vercel**: Зайдите на [vercel.com](https://vercel.com), войдите через GitHub.
4. **Импорт**: Нажмите "Add New Project", выберите ваш репозиторий и нажмите "Deploy".

**Всё! Ваш сайт в сети.** При каждом обновлении файлов на GitHub, сайт обновится автоматически.
